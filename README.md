# Node.js Project

Node.js Project is an Express, MongoDB, and Passport practice application with server-rendered EJS views, local authentication, sessions, and basic route composition.

## Highlights

- Express application with EJS templates
- Passport local-auth integration
- Session-based authentication flow
- MongoDB persistence through Mongoose
- Good base project for learning full-stack Node.js fundamentals

## Tech Stack

- Node.js
- Express
- Mongoose
- Passport
- EJS
- express-session

## Getting Started

```bash
npm install
cp .env.example .env
npm run dev
```

## Environment Variables

- `PORT`
- `SESSION_SECRET`
- `MONGO_URL`

## Notes

This repository is best positioned as a server-rendered Node.js learning project rather than a finished product.
